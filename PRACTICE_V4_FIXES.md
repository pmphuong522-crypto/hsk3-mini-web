# Practice V4 — fixes after real learner test

## 1. T6/T7 feedback
When a matching exercise is submitted incorrectly, feedback now shows each Hanzi item, the learner-selected pair (or “Chưa nối”), and the correct meaning/Pinyin for that item. If all 4 pairs are correct, feedback shows 4/4.

## 2. End-of-session navigation
The summary screen no longer uses “Về Flashcard” as its primary navigation. It now has “← Chọn bài luyện tập”, which returns to the lesson-selection screen. The top-right Flashcard link remains available for returning to the Flashcard module.
